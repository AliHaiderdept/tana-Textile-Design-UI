# SŪTRA — Tactile Textile Design Lab

A digital textile design playground featuring interactive vector weaving, customizable patterns, color controls, weave archives, and a designer moodboard.

## Preview

![SŪTRA Design](./Sutra-Designs/Screenshot 2026-09-16 104557.png)

## Features

* 🧵 Interactive Vector Loom
* 🎨 Custom Warp & Weft Colors
* 🔲 Herringbone, Houndstooth & Basket Weave
* 📐 Adjustable Thread Density
* 📚 Weave Archives
* 🧑‍🎨 Artisan Atelier
* 🎯 Dynamic Designer Moodboard
* ⚡ Alpine.js Interactions
* 🎨 Tailwind CSS
* 🖼️ SVG-based Vector Graphics

## Technologies

* HTML5

## Interactive Loom

The project includes an interactive loom where users can:

* Select weave structures
* Change warp thread colors
* Change weft thread colors
* Adjust thread density
* Zoom into the vector pattern
* Export the weave as SVG
* Order a swatch

## Design

SŪTRA uses a tactile textile-inspired visual language with:

* Organic clay tones
* Indigo
* Sage
* Ochre
* Serif typography
* Linen textures
* Vector thread patterns
* Glass-like cards
* Responsive layouts
